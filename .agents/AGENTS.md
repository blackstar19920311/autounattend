## GitHub Deploy Rule
If the user types the exact word 'GITHUB' (in all caps) or asks to push to GitHub, you must execute the following sequence: run `git add .`, then `git commit -m "Auto-sync"` (or a more descriptive message), and finally `git push origin main`.
CRITICAL UPDATE: From now on, whenever you successfully complete ANY file modifications or tasks, you MUST automatically run the GitHub sync sequence (`git add .`, `commit`, `push`) at the end of your turn WITHOUT asking for permission. This automatic background syncing behavior remains active indefinitely until the user explicitly tells you to stop. Do NOT build the project or push the `dist` folder.
